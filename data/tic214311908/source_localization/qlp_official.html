TESS Lightcurves From The MIT Quick-Look Pipeline ("QLP")

Overview

The Transiting Exoplanet Survey Satellite (TESS) is the first high-precision full-sky photometry survey in space. The MIT QLP team produces light curves from a magnitude limited (TESS magnitude < 13.5) set of stars and other stationary luminous objects from the TESS Full Frame Images (FFIs). The photometric precision roughly follows the theoretical predictions pre-launch. The data reduction process is described in the primary references (Huang et al. 2020a and Huang et al. 2020b). Additional pages in the full QLP data validation report provide additional metrics for decision-making. These plots are useful for diagnosing whether the source of transit-like variability is on target or from a nearby blended source, which is particularly important for FFI data.  Some of these data validation pages are available on the MIT TOI Portal.

The first data release consists of QLP light curves for targets in Sectors 1-26. These data products cover the two-year TESS Primary Mission and include 14,773,977 and 9,602,103 individual light curve segments in the Southern and Northern hemispheres, respectively. The second data release consists of 10-minute cadence light curves for 9.1 million stars from the first year of the first Extended Mission (Sectors 27-39). The third data release consists of 10-minute cadence light curves for 5.7 million stars from the second year of the first Extended Mission (Sectors 40-55). For the second Extended Mission starting in Sector 56 the cadence was improved again to 200 seconds.

As of Sector 94, QLP is now using the TESS-Gaia Light Curve (TGLC) methodology to produce light curves. For more details on QLP, please see the QLP webpage at https://tess.mit.edu/qlp/.

Acknowledgements

Please include the following acknowledgement in published material that makes use of QLP-produced High Level Science Products:

"We acknowledge the use of TESS High Level Science Products (HLSP) produced by the Quick-Look Pipeline (QLP) at the TESS Science Office at MIT, which are publicly available from the Mikulski Archive for Space Telescopes (MAST). Funding for the TESS mission is provided by NASA's Science Mission directorate."

The QLP team encourages users of the QLP Extended Mission HLSP (QLP light curves starting with Sector 27), which are made available on a timely and voluntary basis to the broader astronomical community, to invite one QLP team member for co-authorship and consultation on data analysis. Note that this is not a requirement for using QLP HLSP files or publishing results based on them. Please contact Michelle Kunimoto (mkuni@mit.edu) for a recommendation of which member to include if you decide to invite a QLP member to be a co-author on your QLP-based paper.

Data Products

For details on the file format and contents of the light curve files, see the Data Product Description document.

The light curve files have this data file naming convention:

hlsp_qlp_tess_ffi_<sector>-<tid>_tess_v01_llc.<exten>

where:

  • <sector> = The Sector represented as a 4-digit, zero-padded string, preceded by an 's', e.g., 's0026' for Sector 26.
  • <tid> = The full, 16-digit, zeo-padded TIC ID.
  • <exten> = The light curve data type, either "fits" or "txt".

Data file types:

_llc.fits | _llc.txt QLP light curve.  NOTE: .txt versions only available for Sectors 1-26, inclusive.

Corrected timestamps for QLP Sectors 99-104

A barycentric timing correction error was identified starting in Orbit 210 (second half of Sector 99) onward to Orbit 220 (end of Sector 104) This was in part due to changing interpolation library backends, where expected error-raising conditions no longer triggered, silencing an ephemeris file that had reached the end of its sampling range. Starting Orbit 215 (first half of Sector 102), a new ephemeris file was used; however, the expected columns were not in the same order, and barycentric timing correction was performed on spacecraft velocity values instead of position. This has been corrected using a programmatic approach that does not involve an operator downloading from JPL once a year.

MAST is in the process of updating these sector files with corrected timestamps. Affected Sectors with asterisks (*) in the Sector Availability table below have not yet been redelivered.

Corrected timestamps for QLP Sectors 74-79

QLP uses the TESS ephemeris as predicted by JPL horizons to correct spacecraft time to BJD TDB. A new ephemeris data file is downloaded at the beginning of each year to use for the position of the spacecraft for the duration of that year. The file downloaded for 2024 was generated using the wrong reference plane: the QLP software is designed to use coordinates based on the ICRF equatorial reference plane (i.e., the x-y plane of the ICRF), but the file was generated with coordinates based on the ecliptic plane derived from the ICRF.

As a result, the barycentric correction applied to light curve timestamps was based on the wrong spacecraft position, leading to a timestamp error of up to roughly ±3.0 minutes. The error depends on each star’s CCD position and the difference between the actual spacecraft coordinates and the coordinates from the invalid file, which varied over the course of the year. QLP light curves delivered to MAST for sectors 74-79 (inclusive) were affected by an ephemeris bug (denoted by asterisk). By sector 80, the invalid ephemeris file was identified and fixed, and verification methods were put in place to ensure ephemeris data used by QLP going forward is correct. Light curves for the affected sectors have been corrected and re-uploaded to MAST as version 2 (v02) data products.

Sector Availability

Bulk download shell scripts that use curl are provided to download every light curve in FITS format; similar scripts are availble to download the light curves for Sectors 1 through 26 only in ASCII text format. In addition to the light curve bulk download scripts, the data are also available in the MAST Portal and through the MAST APIs like astroquery.mast.

Target List files are provided that contain the TIC ID, R.A. (J2000, deg), and Dec. (J2000, deg) for targets that have QLP light curves.  For users that have very large target lists, it is recommended you download these .csv files first to cross-match with your list of targets BEFORE you query MAST to search for and download QLP data products.
