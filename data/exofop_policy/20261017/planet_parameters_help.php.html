Guidelines for Submitting Planet Parameters

Planet parameters can be uploaded for a new candidate, an existing candidate, or a confirmed planet.

Bulk upload:

The params_planet_YYYYMMDD_001.txt template is an example of how to create a bar delimited file for parameters for a new candidate, or an existing candidate, or a confirmed planet. See the template for detailed instructions, but in particular the fields for defining the type of planet are:

  • target: TOI, Candidate (note the naming convention is the same for a TESS or other discovery candidate), or Confirmed planet where the prefix of "TOI, TIC, or CONF" respectively indicates hte class of planet.
    • TOI name = TOI125.01, TOI125.02 (must include "TOI" prefix and no spaces)
    • Candidate = TIC52368076.01, TIC52368076.02 (must include "TIC" prefix and no spaces)
    • Confirmed planet name = CONF Wasp-12 b (must include "CONF" prefix and match Confirmed Planet Name in the NASA Exoplanet Archive: Confirmed Planet Table)
  • flag: newctoi - new candidate or newparams - new parameters for an existing candidate or confirmed planet
  • disp: Planet dispositon - optional
  • discovery: leave blank for TESS or enter other source
  • candname: candidate name that is used by a team - optional
