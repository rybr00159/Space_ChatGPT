# Hidden-source stellar-system audit

**TIC 260352037 has coherent primary and half-phase eclipse-like dips in 25
public TESS QLP sectors. Both signal types localize to its unresolved bright
image. A faint eclipsing stellar system is a strong explanation; its component
stars, association and novelty are not established.**

The [full scientific assessment](../../../reports/stellar_systems/hidden_sources.md)
contains measurements, assumptions, counter-tests and exact resume commands.

The other two examined giant-star leads, TIC 271697430 and TIC 406280158,
do not retain comparable phase coherence. Their complete negative/control
measurements and figures are preserved here.

There is no confirmed new star or stellar system. In particular, the Gaia
star 4.21 arcseconds from TIC 260352037 is already catalogued; the question is
whether it hosts an unrecognized eclipsing pair. The current images do not
securely assign that source. Independent prior-recognition results should
be consulted before describing any binary signal as new.
